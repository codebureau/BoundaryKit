# Architecture Decision Records

Short, dated records of design/policy/architecture decisions for BoundaryKit — lighter-weight than a full spec: enough for a Developer to implement against without re-deriving the design. Format: Context / Decision / Consequences.

Written by the `architect` agent (see [`.claude/agents/architect.md`](../../.claude/agents/architect.md)); one file per decision, numbered sequentially.
